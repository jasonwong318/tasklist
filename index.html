🐦 Gitee 雲端同步

          
透過 Gitee 私有倉庫同步任務資料，HTML 文件直接發給成員使用


          
          

            
📲 使用方式（直接分發）

            

              1. 管理者完成下方 Gitee 設定後，把此 HTML 文件 透過微信發給所有成員

              2. 成員收到後，用 手機瀏覽器（Safari / Chrome）開啟

              3. iPhone：點底部「分享」→「加入主畫面」

                 Android：點右上角選單 →「安裝應用」或「加至主畫面」

              4. 加入後桌面出現圖示，開啟即如 原生 App，無需下載
            

          


          

            
🐦 Gitee 數據同步設定

            

              1. 登入 gitee.com → 新建私有倉庫（如 tasklist-data）

              2. 倉庫內新建 data.json，內容填 {} 並提交

              3. 右上角頭像 → 設定 → 私人令牌 → 生成 Token

              4. 填入下方三欄，點「測試連線」確認成功
